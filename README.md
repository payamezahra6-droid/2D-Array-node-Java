# Nodes 2D Array — Java

A simple Java implementation of a **2D array using nodes**, demonstrating how data can be organized in rows and columns without using Java's built-in 2D array.

## Concepts Used

* Nodes
* 2D Data Structure
* Linked Structures
* Rows and Columns
* References
* Object-Oriented Programming
* Java Classes and Objects

## Operations

The program demonstrates:

* Creating nodes for a 2D structure
* Connecting nodes using references
* Organizing nodes into rows and columns
* Storing values in nodes
* Traversing the 2D structure
* Displaying the stored elements
